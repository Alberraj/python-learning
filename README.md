# GitHub API Tool

A simple Python command-line tool for working with the GitHub REST API.

## Features

- Check GitHub API status
- Find GitHub user profiles
- Find GitHub repositories
- Display public repository information
- Handle API errors and connection errors
- Uses Python `requests`
